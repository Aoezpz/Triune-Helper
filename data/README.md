# Bundled data — where each file came from

Two generated files live here. They are checked in so the app works offline and
on its first line, but they have different origins and that matters if this
repository is public.

## `progression.json`

Generated by `scripts/export-progression.mjs` from a **PTDex** deployment - the
item and spell database one particular trio server publishes. Expansion gates
and Plane of Time flag steps. Another server's gates will be close but not
identical; this file is the one piece of bundled data that is server-specific.

## `buffs.json`

Generated by `scripts/export-buffs.mjs` from **`spells_us.txt`, a data file that
ships with the EverQuest client**. It holds 1,833 spell names paired with the
effect messages that announce them, kept only where a message identifies exactly
one spell.

That content originates with Daybreak Game Company, not with this project, and
the MIT licence in `/LICENSE` does not extend to it. It is included here on the
same footing as every other EverQuest log parser of the last twenty years —
long-standing community practice rather than a grant of permission from anyone.

If that is not a footing you want to publish on, delete this file and have
people build their own from the client they already own:

```bash
node scripts/export-buffs.mjs "<EQ>\spells_us.txt"
```

Note that `src/main/buffs.ts` imports it statically, so removing it from the
repository without also switching that import to a runtime read with a fallback
will break the build rather than degrade the buff board.
